# Apuntes de Ciencia de Datos

## Sinopsis general

Estos apuntes abordan una introducción práctica y teórica al aprendizaje automático y a las redes neuronales, con enfoque en su aplicación en problemas reales de clasificación, regresión y análisis de datos. El material está organizado para que el estudiante pase desde los conceptos básicos hasta la construcción de modelos más complejos usando Python, TensorFlow y Keras.

### Temas principales que se desarrollarán

- Fundamentos del aprendizaje automático y redes neuronales.
- Conceptos de perceptrón, pesos, sesgos, activación, errores y ajuste de parámetros.
- Entrenamiento de modelos mediante descenso del gradiente y actualización de pesos.
- Funciones de activación como ReLU, sigmoid y softmax.
- Redes neuronales densas para clasificación y regresión.
- Uso de TensorFlow y Keras para crear, compilar y entrenar modelos secuenciales y funcionales.
- Preparación de datos, partición train/validation/test y evaluación de métricas.
- Uso de redes convolucionales para procesamiento de imágenes y transferencia de aprendizaje.
- Aplicación de modelos a problemas reales mediante un proyecto práctico con datos de pacientes.

### Estructura del repositorio

- Perceptrón: introducción a la lógica de redes neuronales simples y su entrenamiento.
- Redes densas: redes multicapa, clasificación no lineal y conceptos avanzados de arquitectura.
- CNN y visión computacional: redes convolucionales, procesamiento de imágenes y aprendizaje transferido.
- Taller: proyecto final con aplicación de un modelo sobre datos reales, preprocesamiento y evaluación.

### Objetivo del curso

El propósito de estos apuntes es que el estudiante comprenda cómo funcionan las redes neuronales desde lo más básico hasta su implementación con librerías modernas, desarrollando la capacidad de resolver problemas de ciencia de datos con un enfoque práctico y analítico.

---

Estos apuntes combinan teoría, ejemplos numéricos, ejercicios en notebooks y aplicaciones concretas para facilitar el aprendizaje progresivo de la inteligencia artificial y el deep learning.
